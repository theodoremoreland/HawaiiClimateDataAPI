Summary

This API is built atop a hawaii.sqlite database. The database features Hawaii climate data between January 2010 and August 2017. An analysis of said data can be found in the form of a Jupyter Notebook. You can perform your own analysis by querying one of four available HTTP routes. You can also visit the documentation.

Aggregates can be queried via GET request at the aggregate route like so GET @ /api/v2/aggregate/2010-01-01/2017-08-23
